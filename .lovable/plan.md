# Simplify TextCraft with a Material 3-inspired design

## What will change
- Remove the first-visit splash and loading screens so the app opens directly to its content.
- Replace the homepage's animated hero, marquee, fabricated metric cards, stacked category panels, and glowing hover effects with a calm, direct tool directory.
- Keep all existing tools and destinations, with clear category headings and compact, accessible tool links.
- Simplify shared colors, surfaces, navigation, and repeated card styling toward Material 3: tonal surfaces, restrained color, clear hierarchy, and small-radius shapes.
- Remove decorative particle and continuous rotation/spinning effects, while preserving useful tool behavior and theme switching.

## Implementation details
- Update the app entry, homepage, shared header/footer/mobile navigation, and shared visual styles; remove obsolete splash/loading display code if no longer referenced.
- Verify the homepage and a representative tool page at desktop and mobile sizes, and check the preview build log.
