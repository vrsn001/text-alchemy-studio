# Make TextCraft a simple directory of real tools

## What will change
- Replace misleading homepage entries with a short list of tools that have working functions and real destinations.
- Give retained tools clear, dedicated subpages with accurate names and descriptions; remove aliases that only lead to unrelated tools.
- Add a simple, static TextCraft introduction above the directory, without a splash screen or opening animation.
- Remove decorative effects that make the site feel cluttered, while keeping the existing light/dark themes and simple Material 3 surfaces.
- Leave the unclear “starter” item untouched until it is identified.

## Technical approach
- Reuse existing tool pages and shared controls; add a small route only where a retained working tool does not already have one.
- Keep the homepage category-grouped and ensure every visible tool links to its actual function.
- Preserve current navigation and keep animations compatible with reduced-motion preferences.

## Validation
- Check every homepage destination against its page and verify each retained tool performs its named action.
- Verify the homepage and a representative tool page on phone and desktop, then check the preview build.
